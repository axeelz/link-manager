How it works

One Bun process serves the redirects, the API and these pages.

Bun
Runtime, test runner and bundler for the pages, all in one.
Elysia
Routes and validation. Eden turns them into a typed client, no codegen.
Drizzle
Typed SQL and migrations, applied automatically at startup.
Turso
SQLite at the edge in production, a local file in development.
React
The admin, with plain CSS and no component library.
